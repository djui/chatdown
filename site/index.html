Your AI chats,
as clean Markdown.

Chatdown exports ChatGPT, Codex, Claude and Claude Code conversations to tidy Markdown, or to HTML, PDF, plain text and JSON. You pick exactly which messages go in, and whether the AI's thinking and tool use come along.

    What comes out is worth keeping
    
        
    Chatdown reads the conversation itself, not a screenshot of it, so the file is faithful and quiet.
    
      
    
      
    
        
    
          
    Keep only what matters
    
          
    Leave out any message, in the side panel or with the checkboxes Chatdown adds next to each message in the chat itself. Quick filters keep only yours, only the answers, or everything.
    
        
    
        
    
          
    Only the branch you see
    
          
    Edited a prompt or regenerated an answer? Chatdown follows the branch that's on screen and skips the abandoned ones.
    
        
    
        
    
          
    Thinking and tool use, if you want them
    
          
    Reasoning, searches, code runs and their results fold into collapsible <details> blocks, or are left out entirely.
    
        
    
        
    
          
    Code stays code
    
          
    Fenced blocks keep their language, nested fences are escaped, and Claude artifacts are exported as titled code blocks.
    
        
    
        
    
          
    Markdown, HTML, PDF, text or JSON
    
          
    One click to switch formats. The HTML page is a single readable file; PDF goes through Chrome's own Save as PDF; JSON keeps every block for your own tools. Markdown can start with note properties for Obsidian or a docs repo.
    
        
    
        
    
          
    Nothing leaves your browser
    
          
    No servers, no accounts, no analytics. Chatdown asks the site you're on for the chat, using the session you already have.

    Questions
    
      
    
        Does Chatdown send my conversations anywhere?
        
    No. It has no server. When you open the panel it asks the site you're on, for example chatgpt.com, for the current conversation, using the login you already have, and turns it into Markdown inside your browser. The only thing it stores is your export options.
    
      
    
      
    
        Why does it need these permissions?
        
    Side panel for the UI, access to chatgpt.com and claude.ai to read the open conversation, tabs to notice when you switch chats, scripting to work in tabs that were open before you installed it, and storage for your options. It can't see any other site.
    
      
    
      
    
        What about regenerated answers and edited prompts?
        
    For ChatGPT and Claude, Chatdown exports the branch you're looking at, the same path through the conversation you see on screen. Switch branches in the chat, then press reload in the panel to export a different one.
    
      
    
      
    
        Codex or Claude Code missed something. Why?
        
    For those two, Chatdown reads the rendered page rather than the underlying data, and their pages change often. If an export looks off, please open an issue with the page type, and we'll tighten the selectors.
    
      
    
      
    
        Which formats can I export?
        
    Markdown, a self-contained HTML page, PDF, plain text and JSON. PDF uses Chrome's own Save as PDF, so the text stays selectable and nothing is uploaded. Copying in HTML or PDF mode puts formatted text on the clipboard, ready to paste into Docs, Notion or an email.
